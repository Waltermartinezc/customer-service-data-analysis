# Customer Service Data Analysis

## 📊 Descripción

Proyecto de análisis de datos enfocado en evaluar el desempeño y la experiencia del cliente en un servicio de atención.

El objetivo es analizar interacciones con clientes, identificar tendencias y detectar oportunidades de mejora a partir de indicadores de calidad y satisfacción.

## 🎯 Objetivos

- Analizar datos de interacciones con clientes.
- Identificar tendencias en satisfacción.
- Detectar principales motivos de contacto.
- Analizar oportunidades de mejora.
- Generar insights que apoyen la toma de decisiones.

## 🛠️ Tecnologías

- Python
- Pandas
- SQL
- Jupyter Notebook
- Power BI
